# 📦 トレーサビリティ（食品工場 原料受入・仕込みロット管理）

食品工場における原料受入時のロット登録から、製造仕込み時の使用原料ロット紐づけ、および双方向のロット追跡（トレースバック・トレースフォワード）を行う Web アプリケーションです。

## 🔗 公開アプリ URL

- **本番アプリ:** https://blank-app-i3grnklynm.streamlit.app/

> 現場のタブレットやスマートフォンのブラウザで上記 URL を開き、ホーム画面に追加しておくとスムーズに運用できます。

## 主な機能

1. **原料受入登録（`1.原料受入` タブ）**
   - 対象原料（**小麦粉・液卵・イースト・乳化剤・全粒粉**）の選択
   - 仕入先、原料ロットNo、賞味期限、受入数量・単位の登録
   - 日本標準時（JST）での受入日時自動記録と在庫一覧表示

2. **仕込み・ロット紐づけ（`2.仕込み紐づけ` タブ）**
   - 受入済みの「使用中」ロットのみをプルダウンに連動表示し、入力ミスを防止
   - 製品名・製造ロットNo（仕込みバッチ）に対する使用原料ロット・使用数量の紐づけ登録
   - 「使い切り（使用済）」チェックによる使用済みロットの選択肢除外

3. **双方向トレース検索（`3.双方向トレース検索` タブ）**
   - **トレースバック（製品ロット → 使用原料を追跡）：** 製造ロットNoや製品名から、使用された全原料のロットNo・仕入先・賞味期限・使用量を抽出
   - **トレースフォワード（原料ロット → 製造された製品を追跡）：** 原料名・原料ロットNoから、その原料が投入された全製品バッチを抽出
   - 検索結果の CSV ダウンロード出力（Excel 文字化け防止の UTF-8 BOM 付き）
