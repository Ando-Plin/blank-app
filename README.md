# 📦 トレーサビリティ（原料受入・仕込み・出荷納品ロット管理）

食品工場における **原料受入ロットの登録** から **製造仕込み時のロット紐づけ**、さらに **製造ロット別の出荷・納品先記録** までを一元管理し、双方向のロット追跡（トレースバック・トレースフォワード）を行う Web アプリケーションです。

## 🔗 公開アプリ URL

- **本番アプリ:** https://blank-app-i3grnklynm.streamlit.app/

> 現場のタブレットやスマートフォンのブラウザで上記 URL を開き、ホーム画面に追加しておくとスムーズに運用できます。

## 主な機能

1. **原料受入登録・編集（`1.原料受入` タブ）**
   - 対象原料（**小麦粉・液卵・イースト・乳化剤・全粒粉**）の選択
   - 仕入先、原料ロットNo、賞味期限、受入数量・単位の登録
   - 一覧テーブル上での直接セル編集および行削除に対応

2. **仕込み・ロット紐づけ・編集（`2.仕込み紐づけ` タブ）**
   - 受入済みの「使用中」ロットのみをプルダウンに連動表示し、入力ミスを防止
   - 製品名・製造ロットNo（仕込みバッチ）に対する使用原料ロット・使用数量の紐づけ登録
   - 「使い切りにする」チェックによる使用済みロットの選択肢除外、および登録後の一覧編集・削除

3. **出荷・納品登録・編集（`3.出荷・納品登録` タブ）**
   - 仕込み済みの製造ロットNoを選択し、製品名を自動補完
   - 納品日、納品先（取引先・店舗名）、納品量・単位、備考（伝票No等）の紐づけ登録
   - 納品履歴一覧の直接編集および行削除に対応

4. **双方向トレース検索（`4.双方向トレース` タブ）**
   - **トレースバック（納品先・製品ロット → 原料を追跡）：** 納品先や製造ロットNoから、使用された全原料のロットNo・仕入先・賞味期限・使用量を一括抽出
   - **トレースフォワード（原料ロット → 製品・納品先を追跡）：** 原料名・原料ロットNoから、その原料が投入された製造バッチおよび出荷先の納品先・納品量までを一気通貫で追跡
   - 検索結果の CSV ダウンロード出力（Excel 文字化け防止の UTF-8 BOM 付き）
